# Milestone 3 — deep notes and actionable tutorials

Deliver source-aware notes and actions with explicit long-video coverage.

## Deliverables

- Manual generation; automatic sampled overview is opt-in.
- Deep mode snapshots all captured caption/OCR chunks, processes bounded sections, persists progress, and supports pause/continue.
- Quick mode samples across the source and shows selected/total chunks.
- Notes contain summary, concepts, literal code when available, actions and clearly marked exploration questions.
- Actions preserve source order, commands, warnings and prerequisites; missing steps are not invented.
- Citations are remapped correctly when multiple sections are combined.
- Sanitized Markdown, copy, Markdown download and Unicode-capable browser print/PDF export.

## Acceptance

Deep batching covers every input chunk exactly once. Partial generation is visibly partial and can continue. Invalid or unavailable verification is unchecked. Exported Markdown contains source video/timestamp links. Code that is not readable in the source is not labeled exact.

## Competitive target

Evaluate fact coverage, unsupported statements, instruction completeness, command fidelity and editability against leading summarizers/study tools. Editable notes, structured action checklists and learning assessment are future product improvements.
