# Milestone 4 — connected memory and comparative research

Deliver persistent, provenance-preserving graph memory and research over selected saved videos.

## Deliverables

- User-triggered concept extraction to avoid surprise provider calls.
- JSON schema checks, valid evidence refs, normalized node identity and validated relationships.
- Merge nodes/edges without duplicate provenance; retain source excerpts after temporary sessions expire.
- Searchable graph with selectable/keyboard-operable nodes, relationships and source timestamps.
- Pin/unpin library, BM25 research retrieval with representation across matching source videos.
- Research outputs distinguish agreement, disagreement and missing evidence.
- Graph JSON and Markdown/PDF report export.

## Acceptance

Related videos merge stable concept identities; dangling/fabricated relationships are discarded. Graph evidence survives temporary expiry. Research uses pinned evidence only, preserves citations, and refuses empty retrieval. Source diversity is tested.

## Competitive target

Recall is an explicit knowledge-memory benchmark; a graph alone is not novel. Measure entity/edge precision, duplicate rate, answer citation coverage and contradiction recall. Semantic entity resolution, large-graph navigation and hybrid retrieval remain measurable gaps.
